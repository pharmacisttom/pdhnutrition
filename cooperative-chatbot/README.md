# ศูนย์บริการสมาชิกสหกรณ์ผ่าน LINE OA

ระบบแยกจาก PDH Nutrition ใช้ PHP 8 / PDO SQLite / cURL ไม่ใช้ฐานข้อมูลโรงพยาบาล

## เริ่มต้นบน XAMPP

1. เปิด Apache และเรียก `D:\xampp\php\php.exe setup.php` จากโฟลเดอร์นี้ ตั้งชื่อเจ้าหน้าที่และรหัสผ่านอย่างน้อย 12 ตัวอักษร ไม่มีรหัสผ่านเริ่มต้น
2. เปิด `http://localhost/pdhnutrition/cooperative-chatbot/` เพื่อล็อกอิน
3. เพิ่มคำถาม คำค้นคั่นด้วยจุลภาค และคำตอบจริง ตรวจสอบแล้วติ๊กเปิดใช้งาน ไม่มีการสมมติอัตราดอกเบี้ยหรือเวลาทำการ
4. แก้ `config.local.php` ใส่ Channel secret และ Channel access token ของ LINE Messaging API เก็บไฟล์นี้เป็นความลับ
5. นำขึ้นเซิร์ฟเวอร์ HTTPS ที่ LINE เข้าถึงได้ ตั้ง Webhook เป็น `https://โดเมน/pdhnutrition/cooperative-chatbot/webhook.php` เปิด Use webhook และ Webhook redelivery ปิดข้อความตอบกลับอัตโนมัติใน OA ที่จะตอบซ้อนกับระบบ
6. เปิด worker ด้วย `D:\xampp\php\php.exe worker.php` ให้รันต่อเนื่องและเริ่มอัตโนมัติเมื่อเซิร์ฟเวอร์เปิด Worker ต้องเริ่มก่อนรับแชตเพราะ reply token มีอายุสั้น `--once` ใช้ตรวจคิวครั้งเดียว ไม่เหมาะแทน worker ต่อเนื่อง

## การใช้งาน

- เจ้าหน้าที่รีเฟรชหน้ารับเรื่องเพื่อดูข้อความล่าสุด เลือกสมาชิก แล้วรับเรื่องก่อนตอบ บอตจะหยุดขณะรอหรือมีเจ้าหน้าที่ดูแล
- เจ้าหน้าที่อื่นรับเรื่องที่มีผู้ดูแลแล้วไม่ได้ ปิดเรื่องแล้ว ข้อความครั้งถัดไปจะเริ่มตรวจ FAQ ใหม่
- ส่งข้อความเจ้าหน้าที่ผ่าน push API ส่วนคำตอบบอตผ่าน reply API หน้าแชตแสดง pending/sending/sent/failed โดย sent หมายถึง LINE รับ API แล้ว ไม่ใช่สมาชิกอ่านแล้ว
- รองรับข้อความตัวอักษร สื่อชนิดอื่นแสดงชนิดข้อความแล้วส่งเข้าคิว ยังไม่มีการดาวน์โหลดไฟล์แนบ
- ผูกเลขสมาชิกและยอดเงินได้ด้วยการบันทึกโดยเจ้าหน้าที่ผู้รับเรื่อง ต้องตรวจตัวตนจากทะเบียนก่อนติ๊กยืนยัน ไม่ใช้เลขสมาชิกที่ผู้ส่งพิมพ์เป็นหลักฐาน และไม่ส่งยอดเงินอัตโนมัติผ่านบอต
- เพิ่มผู้ใช้โดยเพิ่ม username => password_hash ใน `staff` ของ config.local.php เจ้าหน้าที่ทุกรายมีสิทธิ์จัดการ FAQ และดูข้อมูลเท่ากันในรุ่นนี้
- คำค้นตรงหลาย FAQ จะส่งให้เจ้าหน้าที่ ไม่มี AI เดาข้อมูล

## การตรวจสอบ

เรียก `D:\xampp\php\php.exe test.php` ทดสอบฐานข้อมูลในหน่วยความจำ ไม่เรียก LINE API

## ก่อนใช้งานจริง

ต้องมี HTTPS, LINE credentials, worker ที่มีผู้ดูแล และคำตอบที่อนุมัติแล้ว ทดสอบกับ OA ทดสอบก่อนเปิดให้สมาชิก 3,000 คน จำนวนสมาชิกไม่ใช่จำนวนผู้ใช้งานพร้อมกัน ยังไม่ได้ทดสอบโหลดจริงหรือเชื่อมฐานข้อมูลสมาชิก ข้อมูลยอดเงินเป็นข้อมูลที่เจ้าหน้าที่บันทึก ไม่ใช่ยอดบัญชีปัจจุบันจากสหกรณ์

Apache ต้องอ่าน `.htaccess` เพื่อปิดการเข้าถึง storage และไฟล์ตั้งค่า หากใช้ Nginx ต้องตั้ง deny สำหรับ storage, config*.php, bootstrap.php, worker.php, setup.php, test.php เอง ตรวจว่า HTTP เข้า config.local.php และ storage/chat.sqlite แล้วได้ 403 ก่อนใช้งานจริง SQLite ต้องอยู่บน local disk ที่เขียนได้ สำรองฐานข้อมูลด้วย SQLite backup API หรือหยุด worker/เว็บก่อนคัดลอกฐานข้อมูลพร้อม WAL ไม่สำรองเฉพาะ chat.sqlite ขณะมีการเขียน

Push ที่ส่งไม่สำเร็จชั่วคราว retry สูงสุด 5 ครั้งโดยใช้ retry key เดิม Reply ที่ผิดพลาดจะขึ้น failed ไม่เปลี่ยนเป็น push อัตโนมัติ ต้องตรวจสถานะในหน้าการเชื่อมต่อและตอบใหม่โดยเจ้าหน้าที่ บันทึกประวัติการทำงานใน audit ยังไม่มีระบบ retention, แยกสิทธิ์ตามฝ่าย หรือเชื่อมบัญชีสมาชิกผ่าน OTP

เอกสาร LINE: https://developers.line.biz/en/docs/messaging-api/receiving-messages/
